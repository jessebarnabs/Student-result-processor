# Simple Student Result Processor

A simple Python program that processes student results. Built while learning Python at Africa International University.

## Files
- `Main.py`: the main program. Run this file to start it.
- `grading_utils.py`: helper functions used by the main program for grading.
- `mini_challenge.py`: a small practice challenge.
- `test_module.py`: a file used to test the code.
